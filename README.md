# Online Healthcare Management System
Frontend-only prototype (HTML5, CSS3, Vanilla JS, localStorage). Admin, Doctor and Patient dashboards share data through localStorage.

## How to run
1. Copy the whole folder. 2. Keep the structure. 3. Double-click `index.html`. No npm, server or database.

## Login
Any non-empty User ID/email and password work. Pick a role, or use the "Continue as ..." demo buttons.

## Demo flow
Patient: book appointment → Logout → Doctor (pick the same doctor in "Viewing as"): Confirm → Patient sees Confirmed → Admin sees it in Appointments.

## Disclaimer
Prototype with fictional healthcare data. Not for real medical use.
